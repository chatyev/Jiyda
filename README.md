# Drift

Лёгкий браузер в духе Arc для Windows. Ядро написано на Rust, страницы рендерит WebView2 (Chromium из Edge, уже встроен в Windows 10/11).

## Что умеет (v0.1)

- Вертикальная панель вкладок: закреплённые сверху, обычные ниже, перетаскивание мышью (в том числе между разделами).
- Командная палитра в стиле Arc: поиск по открытым вкладкам и истории, адрес или поисковый запрос.
- Закреплённые вкладки помнят свой адрес. Если ушёл с него, появится кнопка ↺. Ctrl+W не удаляет закреплённую вкладку, а выгружает её.
- Автоархив: незакреплённые вкладки, которые не открывали 12 часов, при запуске уходят в «закрытые» (вернуть через Ctrl+Shift+T).
- Сон вкладок: фоновые вкладки, не открывавшиеся 60 минут, выгружаются из памяти (проверка раз в минуту). Вкладки, где играет звук, не засыпают.
- Сессия сохраняется: после перезапуска всё на месте, а неактивные вкладки грузятся только при открытии.
- Ctrl+клик и клик колёсиком по ссылке открывают её в фоновой вкладке.
- Защита от спама вкладками: страница может открыть не больше 10 вкладок за 5 секунд, а управлять браузером может только через безопасные горячие клавиши.
- Поиск по странице (Ctrl+F): все совпадения подсвечиваются, счётчик «3 из 7».
- Загрузки (Ctrl+J): список скачанных файлов с поиском. Вкладка, открытая только ради загрузки, закрывается сама.
- Команды в палитре: начни вводить, например, «очистить» или «загрузки». «Очистить историю» и «Очистить данные сайтов» (куки, кэш, пароли) спрашивают подтверждение.
- Окно без системной рамки, как в Arc: кнопки окна справа вверху сайдбара, окно тянется за пустое место сайдбара, двойной клик там разворачивает его. Прилипание к краям экрана работает как обычно.
- Split View: две вкладки рядом. В меню вкладки — «Открыть рядом с текущей», в палитре — «Разделить экран» (можно открыть рядом и новый адрес). Разделитель между половинами тянется, пара — одна строка в сайдбаре и сохраняется в сессии. Если закрыть одну половину, вторая займёт всё место.
- Пространства (Spaces): у каждого свои вкладки, цвет и **свои куки и логины** — например, в «Работе» один аккаунт Google, в «Личном» другой. Значки внизу сайдбара: клик — перейти, «+» — новое, правый клик — переименовать, цвет, удалить. Расширения из папки `extensions` работают во всех пространствах; история и загрузки общие. На каждое открытое пространство WebView2 запускает свои процессы, это примерно +100–200 МБ памяти.
- Расширения: распакованные расширения из папки `extensions` (см. ниже).

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+T | новая вкладка (палитра) |
| Ctrl+L | изменить адрес текущей вкладки |
| Ctrl+W | закрыть вкладку (закреплённую — выгрузить) |
| Ctrl+Shift+T | вернуть закрытую |
| Ctrl+Tab / Ctrl+Shift+Tab | следующая / предыдущая вкладка |
| Ctrl+1…8, Ctrl+9 | вкладка по номеру / последняя |
| Ctrl+Shift+1…9 | пространство по номеру |
| Ctrl+S | скрыть / показать панель |
| Ctrl+D | закрепить / открепить |
| Ctrl+Shift+U | скопировать адрес страницы |
| Ctrl+F | найти на странице (Enter / Shift+Enter — следующее / предыдущее, Esc — закрыть) |
| Ctrl+J | загрузки: выбери файл, чтобы показать его в папке |
| Ctrl+R, F5 | обновить |
| Alt+← / Alt+→ | назад / вперёд |
| Ctrl+колесо, Ctrl+= / Ctrl+- | масштаб |
| F12 | инструменты разработчика |

Клавиши работают на любой странице (в том числе пустой) и на русской раскладке: браузер ловит их до страницы, так что сайт не может ни перехватить их, ни подделать.

## Сборка и запуск

1. Установи Rust: <https://rustup.rs> (при установке согласись поставить Visual Studio Build Tools, если попросит).
2. В папке проекта:

   ```
   cargo run --release
   ```

   Готовый файл будет в `target\release\drift.exe`. Его можно закрепить на панели задач.

Если нет желания собирать локально, залей проект в свой GitHub-репозиторий: workflow `.github/workflows/windows.yml` сам соберёт `drift.exe` (Actions → последний запуск → Artifacts).

## Где лежат данные

`%LOCALAPPDATA%\Drift\`:

- `config.json` — настройки (см. ниже);
- `session.json` — пространства, их открытые и недавно закрытые вкладки;
- `history.json` — история;
- `downloads.json` — список загрузок (Ctrl+J);
- `drift.log` — журнал ошибок (старый уходит в `drift.old.log`, когда вырастет больше 1 МБ);
- `webview\` — куки, кэш, логины сайтов пространства «Основное»;
- `spaces\<номер>\webview\` — то же для остальных пространств (папка удалённого пространства стирается при следующем запуске);
- `extensions\` — распакованные расширения.

### Настройки (`config.json`)

```json
{
  "search_url": "https://www.google.com/search?q=%s",
  "sidebar_width": 260.0,
  "frame_padding": 8.0,
  "archive_hours": 12,
  "sleep_minutes": 60,
  "extensions": true,
  "devtools": true,
  "custom_titlebar": true
}
```

Например, для DuckDuckGo: `"search_url": "https://duckduckgo.com/?q=%s"`. `0` в `archive_hours` или `sleep_minutes` отключает соответствующую функцию. `"custom_titlebar": false` возвращает обычную рамку окна Windows. После правки перезапусти браузер.

### Расширения

WebView2 поддерживает расширения частично. Чтобы попробовать, положи распакованное расширение (папку с `manifest.json`) в `%LOCALAPPDATA%\Drift\extensions\<имя>\` и перезапусти браузер. Неплохо работает uBlock Origin Lite: скачай его zip-релиз с GitHub и распакуй туда.

## Как устроен код

```
src/main.rs    — цикл событий окна
src/app.rs     — ядро: окно, WebView, раскладка, команды
src/tabs.rs    — модель вкладок без WebView: порядок, закрытие, сон/архив, Split View
src/spaces.rs  — пространства: имена, цвета, папки профилей
src/store.rs   — сохранение сессии и истории
src/config.rs  — настройки и пути
src/input.rs   — «адрес или поисковый запрос?»
src/limit.rs   — ограничение частоты (сколько вкладок может открыть страница)
src/logging.rs — журнал drift.log
src/hotkeys.rs — горячие клавиши во вкладках (событие WebView2) и буфер обмена
src/tab.js     — скрипт, встраиваемый в каждую страницу (клики по ссылкам, иконки, звук)
src/find.js    — поиск по странице с подсветкой
ui/index.html  — весь интерфейс: сайдбар, палитра, меню
```

Окно устроено слоями. Внизу лежит WebView с интерфейсом на всё окно (`ui/index.html`), над ним — WebView активной вкладки, сдвинутый вправо на ширину сайдбара. Когда открывается палитра, вкладка временно скрывается, а интерфейс рисует палитру поверх всего.

**Внешний вид меняется без знания Rust.** Цвета задаются переменными в начале `ui/index.html` (`--bg-a`, `--bg-b`, `--bg-c` — градиент, `--accent` и т.д.). HTML вшивается в exe при сборке, так что после правки нужно снова запустить `cargo run --release`. Чтобы отладить сам интерфейс, кликни по панели и нажми F12: откроются DevTools именно для неё.

## Если что-то не так

- **Окно пустое или белое.** Проверь, что установлен WebView2 Runtime: <https://developer.microsoft.com/microsoft-edge/webview2/>.
- **Ошибка при старте после смены настроек `extensions`.** WebView2 не любит менять этот параметр для существующей папки данных. Удали `%LOCALAPPDATA%\Drift\webview\` (это сбросит логины на сайтах).
- **Хочу видеть логи.** Они пишутся в `%LOCALAPPDATA%\Drift\drift.log`. В отладочной сборке (`cargo run`) те же сообщения, плюс отладочные, выводятся и в консоль.
