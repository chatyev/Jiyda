# Jiyda

Спокойный браузер для Windows 11. Ядро написано на Rust, страницы рендерит WebView2.

## Как устроен интерфейс

Во время чтения на экране почти только страница: нет панели вкладок и постоянного сайдбара — навигация появляется, когда она нужна. Модель: **Page → Context → Orbit → Spaces**.

- **Верхняя панель**: Space, назад/вперёд, адрес в центре, Ask Jiyda ✦, меню ⋯ и кнопки окна Windows справа. Пустое место панели тянет окно; работают прилипание к краям, Snap Layouts при наведении на «Развернуть», двойной щелчок, системное меню. Пока читаешь, второстепенные кнопки приглушаются.
- **Адресная строка**: сайт и путь, слева — щит (зелёная точка — соединение защищено и трекеры блокируются). Ctrl+L — изменить адрес, подсказки из открытых страниц и истории; Alt+Enter — новой страницей, Shift+Enter — рядом (Split View).
- **Edge Reveal**: курсор у левого края окна → тонкая подсказка → панель значков: Orbit, Search, Spaces, History, Downloads, Later, Settings.
- **Orbit** (Ctrl+Space) вместо вкладок: **Now** — текущие страницы, **Later** — отложенные, **Archive** — закрытые и давно не открытые. До 12 страниц — карточки с превью, больше — смысловые группы (Разработка, Документация, Исследования, Покупки…). Сверху — **Context**: цепочка переходов текущей страницы. Поиск по названию, адресу, группе и Space; стрелки, Enter, Delete, L — в Later, пробел или Ctrl+клик — выбрать несколько. Карточку можно перетащить к краю окна — Split View.
- **Spaces**: у каждого Space свои страницы, Later, Split View и **свои куки и логины**. Переключатель — щелчок по имени Space или Ctrl+Shift+Space; Ctrl+Shift+1…9 — по номеру. Страницу можно перенести в другой Space (меню страницы в Orbit).
- **Командная палитра** (Ctrl+K): страницы, история, команды, Spaces.
- **Split View**: две страницы рядом; над каждой — только строка с сайтом и действиями (поменять местами, заменить, закрыть половину). Разделитель тянется, двойной щелчок — пополам.
- **New Page** (Ctrl+T): поиск, частые сайты, время и сводка защиты. Esc — вернуться на страницу.
- **Focus Mode** (Ctrl+Shift+F): Edge Reveal выключен, второстепенное скрыто, тосты без действий не показываются.
- **Защита**: встроенная блокировка известных трекеров и рекламных сетей. Счётчики настоящие: по странице — в панели щита, за день — на New Page. Куки отдельно для каждого Space. Защиту можно выключить для сайта.
- **Разрешения сайтов** (камера, микрофон, местоположение, уведомления…): подсказка под адресом — «Разрешить один раз» (ничего не запоминает), «Разрешать всегда», «Запретить». Решения видны и отзываются в настройках.
- **Ask Jiyda**: Claude от Anthropic по ключу API пользователя (Настройки → AI Assistant; ключ хранится в диспетчере учётных данных Windows). Пересказать страницу, объяснить или перевести выделенное, сравнить страницы, разобрать открытые страницы, найти то, что видел, сводка исследования. Текст страниц уходит в Anthropic только по вашему запросу; без ключа ничего не отправляется.
- **Выделенный текст** на странице: панель «Копировать · Найти · Объяснить · Перевести · Ask Jiyda» (отключается в настройках).
- **Peek**: Shift+клик по ссылке — предпросмотр поверх страницы. Закрыли — ничего не добавилось; перешли внутри по ссылке или нажали «Открыть страницей» — стала страницей.
- **Загрузки**: маленькая карточка справа внизу с ходом загрузки и отменой, после — «Открыть» и «Показать в папке». Полный список — Ctrl+J.
- **История** (Ctrl+H): поиск, «Сегодня / Эта неделя / Этот месяц», удаление с Undo, «Вернуть контекст» — открыть страницы, которые смотрели тогда же. **Недавно закрытые** — Ctrl+Shift+H, «Вернуть все».
- **Закладки** (Ctrl+Shift+O): папки, поиск, переименование, перенос между папками, удаление с Undo. ☆ в адресной строке или Ctrl+Shift+D — добавить страницу. Закладки ищутся в адресной строке и палитре.
- **Перенос из Chrome и Edge** (Настройки → Перенос из браузеров; при первом запуске — карточка на New Page): закладки — отдельной папкой, история и значки сайтов. Повторный перенос ничего не удваивает. Пароли и входы на сайты не переносятся: Chrome и Edge шифруют их только для себя.
- **Undo вместо подтверждений**: «Страница закрыта · Отменить», «Отложено в Later · Отменить», «Удалено из истории · Отменить».
- **Окно**: тень и скруглённые углы Windows 11, Snap Layouts, развёрнутый и узкий режимы (сначала прячутся подписи и подсказки, потом сужается адрес), F11 — во весь экран (панель — по наведению на верхний край), полноэкранное видео на страницах.
- **Оформление**: светлая и тёмная тема (по умолчанию как в Windows), высокая контрастность Windows, уменьшение анимаций как в Windows. Интерфейс — на русском, узбекском (латиница) или английском, как в Windows (или выбранный в Настройках).
- **После сбоя** (падение, снятие процесса, отключение питания) страницы и пространства на месте, но сами не загружаются: New Page предлагает «Открыть снова». При выключении или перезагрузке Windows сессия сохраняется, а если в Windows включено «Автоматически сохранять мои перезапускаемые приложения», Jiyda откроется снова после входа.
- Как и раньше: сессия сохраняется, фоновые страницы засыпают, давно не открытые уходят в Archive, ссылки из других программ открываются в уже запущенном Jiyda, автообновление с GitHub Releases.

## Установка

Скачай `JiydaSetup-<версия>.exe` со страницы Releases и запусти. Установщик ставит Jiyda для текущего пользователя (без прав администратора) в `%LOCALAPPDATA%\Programs\Jiyda`, создаёт ярлык в «Пуске» и, если отметить, на рабочем столе. Удаляется через «Параметры → Приложения»; вкладки, пространства и логины при этом остаются в `%LOCALAPPDATA%\Jiyda`.

Пока программа не подписана сертификатом, Windows SmartScreen при первом запуске установщика предупредит о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Сборка и запуск

1. Установи Rust: <https://rustup.rs> (при установке согласись поставить Visual Studio Build Tools, если попросит).
2. В папке проекта:

   ```
   cargo run --release
   ```

   Готовый файл будет в `target\release\jiyda.exe`.

3. Установщик (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

   ```
   powershell -ExecutionPolicy Bypass -File installer\build.ps1
   ```

   Получится `target\installer\JiydaSetup-<версия>.exe`; версия берётся из `Cargo.toml`.

GitHub Actions (`.github/workflows/windows.yml`) при каждом push собирает `jiyda.exe` и установщик (Actions → последний запуск → Artifacts). Чтобы выпустить версию: подними `version` в `Cargo.toml`, напиши release notes на английском в `docs/releases/v<версия>.md` (без них релиз не соберётся), закоммить и поставь метку — установщик с этим описанием сам появится в Releases:

```
git tag v0.2.0
git push --tags
```

## Где лежат данные

`%LOCALAPPDATA%\Jiyda\`:

До версии 0.6.0 браузер назывался Seyro (`%LOCALAPPDATA%\Seyro\`), а ещё раньше — Drift (`%LOCALAPPDATA%\Drift\`). При первом запуске Jiyda старая папка сама переименовывается в `Jiyda`: вкладки, пространства, логины на сайтах и ключ Ask Jiyda сохраняются. Если старый браузер в этот момент ещё открыт, Jiyda поработает со старой папкой и перенесёт её при следующем запуске. Установщик Jiyda ставится поверх Seyro (тот же AppId) и убирает его программу и ярлыки; внутренние имена в реестре (`SeyroHTML`, `StartMenuInternet\Seyro`) оставлены прежними, чтобы не сбросился выбор браузера по умолчанию.

- `config.json` — настройки (см. ниже);
- `session.json` — Spaces, их страницы (Now и Later), Split View и Archive;
- `history.json` — история;
- `bookmarks.json` — закладки;
- `downloads.json` — список загрузок (Ctrl+J);
- `jiyda.log` — журнал ошибок (старый уходит в `jiyda.old.log`, когда вырастет больше 1 МБ);
- `running` — метка «Jiyda работает»: снимается при выходе, осталась — прошлый запуск оборвался;
- `webview\` — куки, кэш, логины сайтов пространства «Основное»;
- `spaces\<номер>\webview\` — то же для остальных пространств (папка удалённого пространства стирается при следующем запуске);
- `extensions\` — распакованные расширения;
- `permissions.json` — запомненные разрешения сайтов;
- `favicons.json` — значки сайтов (их отдаёт сам WebView; интерфейс за значками в сеть не ходит);
- `shield.json` — сколько трекеров и рекламы заблокировано за сегодня.

### Настройки (`config.json`)

Почти всё меняется в **Настройках** Jiyda; файл можно править и руками (после правки перезапустите браузер).

```json
{
  "search_url": "https://www.google.com/search?q=%s",
  "archive_hours": 12,
  "sleep_minutes": 60,
  "extensions": true,
  "devtools": true,
  "custom_titlebar": true,
  "check_updates": true,
  "language": "auto",
  "shortcuts": { "orbit": "Alt+O" },
  "shield": true,
  "shield_allow": ["example.com"],
  "selection_toolbar": true,
  "edge_reveal": true,
  "dim_chrome": true,
  "motion": "system",
  "ai": false,
  "download_dir": ""
}
```

`0` в `archive_hours` или `sleep_minutes` отключает соответствующую функцию. `"custom_titlebar": false` возвращает обычную рамку окна Windows. `shortcuts` — переназначенные сочетания (`""` — без сочетания). `shield_allow` — сайты, где защита выключена. `motion`: `"system"` или `"reduced"`. Ключ Ask Jiyda в этом файле не хранится.

Для разработки: переменная окружения `JIYDA_DATA_DIR` задаёт другую папку данных (такой Jiyda не мешает основному). В отладочной сборке с `JIYDA_AUTOMATION=1` браузер выполняет команды из `automation.txt` в папке данных (по строке: `ui {json}`, `cmd имя`, `js код`, `jsfile путь`, `size ширина высота`) — на этом построены тесты E2E. **Все тесты и как их запускать — [tests/README.md](tests/README.md).**

### Расширения

WebView2 поддерживает расширения частично. Чтобы попробовать, положи распакованное расширение (папку с `manifest.json`) в `%LOCALAPPDATA%\Jiyda\extensions\<имя>\` и перезапусти браузер. Неплохо работает uBlock Origin Lite: скачай его zip-релиз с GitHub и распакуй туда.


## Как устроен код

```
src/main.rs        — цикл событий окна
src/app/           — ядро браузера (`App`): mod.rs — структура и общие помощники, остальное — методы по темам:
                     init (создание), session, updates, layout, ui_bridge (состояние для интерфейса),
                     pages, space_ops, split, data, prefs, ask, peek, commands, events, home
src/engine/        — Engine Abstraction: граница ядра и движка страниц. mod.rs — интерфейс (PageView, PageEvent, Engine), webview2/ — единственная реализация (wry + WebView2 COM: страницы, интерфейс, клавиши, защита, разрешения, загрузки). wry и WebView2 видны только там — это проверяет тест
src/ipc.rs         — сообщения интерфейса → ядро (граница интерфейса и ядра)
src/command.rs     — команды браузера (горячие клавиши, меню, палитра)
src/settings.rs    — изменения настроек из Settings и их проверка
src/page_list.rs   — модель страниц без движка: Now/Later, закрытие, сон и архив, Split View, Context, Ctrl+Tab
src/orbit.rs       — смысловые группы Orbit
src/spaces.rs      — Spaces: имена, цвета, папки профилей
src/frame.rs       — рамка окна Windows: кнопки окна (Snap Layouts), регион прозрачного интерфейса
src/keymap.rs      — сочетания клавиш и их переназначение
src/hotkeys.rs     — что делать с нажатием (движок спрашивает до страницы), буфер обмена
src/shield.rs      — списки трекеров и рекламы, исключения сайтов, счётчик за день
src/permissions.rs — запомненные разрешения сайтов
src/ai.rs          — Ask Jiyda (Anthropic Messages API; ключ — в диспетчере учётных данных Windows)
src/net.rs         — HTTPS через WinHTTP
src/instance.rs    — один экземпляр программы, ссылки из других программ
src/i18n.rs        — язык сообщений ядра
src/update.rs      — автообновление с GitHub Releases
src/store.rs       — сессия, история, загрузки
src/bookmarks.rs   — закладки: дерево папок, Undo, перенос без повторов
src/import.rs      — перенос из Chrome и Edge: профили, закладки, история и значки (SQLite)
src/config.rs      — настройки и пути
src/input.rs       — «адрес или поисковый запрос?»
src/limit.rs       — ограничение частоты
src/logging.rs     — журнал jiyda.log
src/recovery.rs    — восстановление после сбоя: метка запуска, перезапуск после обновления Windows
src/tab.js         — скрипт в каждой странице: клики по ссылкам, Peek, панель выделенного текста, иконки, звук
src/find.js        — поиск по странице с подсветкой
ui/index.html      — каркас интерфейса; ui/styles.css — токены темы и стили
ui/js/*.js         — компоненты: core (связь с ядром, слои), region, titlebar, addressbar, spaces, edge, orbit,
                     palette, security, permission, history, closed, ai, downloads, focus, split, find, peek,
                     home, settings, menu, toast, i18n, icons, app
build.rs           — значок и сведения о программе в jiyda.exe
installer/         — установщик Inno Setup
assets/            — бренд
```

**Слои окна.** Внизу — WebView страниц (активная или две половины Split View), сверху — один прозрачный WebView интерфейса. Окно обрезает его регионом (`frame.rs`): интерфейс получает мышь только там, где что-то рисует (верхняя панель, Orbit, тосты, край Edge Reveal), остальное достаётся странице. Поэтому Orbit, палитра и панели появляются поверх живой страницы. Кнопки окна рисует само окно: на `WM_NCHITTEST` оно отвечает как обычное окно Windows, и Windows 11 показывает Snap Layouts.

**Интерфейс и ядро** общаются сообщениями: интерфейс шлёт JSON (`src/ipc.rs`), ядро вызывает `window.jiyda.render(state)` и другие функции (`ui/js/core.js`). Ядро не знает о компонентах интерфейса.

**Внешний вид меняется без знания Rust**: токены темы — в начале `ui/styles.css`. HTML, CSS и JS вшиваются в exe при сборке, так что после правки нужно снова собрать. Ошибки скриптов интерфейса пишутся в `jiyda.log`.

## Если что-то не так

- **Окно пустое или белое.** Проверь, что установлен WebView2 Runtime: <https://developer.microsoft.com/microsoft-edge/webview2/>.
- **Ошибка при старте после смены настроек `extensions`.** WebView2 не любит менять этот параметр для существующей папки данных. Удали `%LOCALAPPDATA%\Jiyda\webview\` (это сбросит логины на сайтах).
- **Хочу видеть логи.** Они пишутся в `%LOCALAPPDATA%\Jiyda\jiyda.log`. В отладочной сборке (`cargo run`) те же сообщения, плюс отладочные, выводятся и в консоль.

```
cargo test
```

Тесты есть у всего, что не требует окна: модель страниц, группы Orbit, сочетания клавиш, защита, разрешения, сообщения интерфейса, Ask Jiyda, разбор адресной строки, история, сессия, настройки. Они же запускаются в GitHub Actions перед сборкой.
