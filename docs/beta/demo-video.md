# Демо-видео Jiyda (план, раздел 31)

25–30 секунд, **без звука**: идея должна читаться по картинке и коротким подписям.
Формат: 1920×1080, 60 кадров/с (для Reels/Shorts — отдельно 1080×1920, кадр по центру окна).

## Подготовка (5 минут)

1. Чистый профиль, чтобы ничего личного не попало в кадр:
   `set JIYDA_DATA_DIR=%TEMP%\jiyda-demo` и запустить `jiyda.exe` из этой же консоли.
2. Два Space: «Работа» (синий) и «Личное» (фиолетовый). В «Работе» открыть 5–6 страниц
   (GitHub, документация, почта, Figma), в «Личном» — 3 (YouTube, новости, Википедия).
3. Пара закладок в папке. Тема — тёмная, окно развёрнуто, масштаб Windows 125%.
4. Запись — OBS Studio (Окно → Jiyda), курсор видимый и неторопливый.

## Раскадровка

| Время | Что в кадре | Подпись (RU / UZ / EN) |
|---|---|---|
| 0–3 с | Jiyda открывается на New Page: поиск со свечением, карточки «Продолжить», «Недавние» | Браузер без полосы вкладок / Varaqlar qatorisiz brauzer / A browser without the tab strip |
| 3–7 с | Ввод «github» в поиск New Page → открывается страница во весь экран, сверху — тонкая панель | Только страница / Faqat sahifa / Just the page |
| 7–11 с | Ctrl+Space → Orbit: все страницы сгруппированы по смыслу, выбрать одну | Все страницы — одним взглядом / Barcha sahifalar — bir qarashda / Every page at a glance |
| 11–15 с | Ctrl+Shift+Space → переключение на «Личное»: окно перетекает в другой цвет, другие страницы | Spaces: у работы и личного свои вкладки и логины / Spaces: ish va shaxsiy alohida / Spaces keep work and life apart |
| 15–19 с | Ctrl+K → палитра: ввести «закл», выбрать закладку | Ctrl+K — всё в одном поиске / Ctrl+K — hammasi bitta qidiruvda / Ctrl+K finds everything |
| 19–23 с | Кнопка 🔖 → панель закладок справа, «Закрепить сбоку» — страница сдвигается | Закладки под рукой / Xatchoʻplar qoʻl ostida / Bookmarks at hand |
| 23–27 с | Закрыть панель, страница снова во весь экран; щит в адресной строке → «трекеры заблокированы» | Защита встроена / Himoya ichida / Protection built in |
| 27–30 с | Логотип Jiyda на тёмном фоне | Jiyda · Rust · Windows · chatyev.github.io/jiyda |

## Чего избегать

- Не показывать в кадре реальные письма, аккаунты и уведомления — только демо-профиль.
- Не ускорять запись: скорость Jiyda — часть идеи.
- Не обещать в подписях того, чего нет («быстрее Chrome» — только со ссылкой на
  бенчмарки, bench/README и /benchmarks на сайте).
