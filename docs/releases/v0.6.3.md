Bookmarks, a one-click move from Chrome and Edge, Uzbek, and Jiyda now recovers gracefully after a crash.

## New

- **Bookmarks.** Press ☆ in the address bar (or Ctrl+Shift+D) to bookmark a page. Ctrl+Shift+O opens your bookmarks: folders, search, rename, move between folders, and delete with Undo. Bookmarks also show up as suggestions in the address bar and the command palette.
- **Move from Chrome and Edge.** Settings → *Import from browsers* brings over your bookmarks, history and site icons from Google Chrome or Microsoft Edge, profile by profile. It works even while the other browser is open, nothing is removed there, and importing again never creates duplicates. On first start, New Page offers it if Chrome or Edge is installed. Passwords and site logins can't be moved: Chrome and Edge encrypt them for themselves only.
- **Oʻzbekcha.** Jiyda is now available in Uzbek (Latin script). It's picked automatically when Windows is in Uzbek, or choose it in Settings → General → Language.
- **Recovery after a crash.** If Jiyda closes unexpectedly (a crash, a killed process, a power cut), your pages and Spaces are all there, but nothing loads by itself: New Page offers *Reopen pages*. If a page was what crashed Jiyda, it won't crash it again on start.

## Fixes

- **Nothing is lost when Windows shuts down.** When Windows restarted or an installer closed Jiyda, the last few seconds of changes could be lost. Jiyda now saves everything before it exits.
- **Jiyda reopens after a Windows update restart,** if *Automatically save my restartable apps* is turned on in Windows.

## Install

Jiyda updates itself: wait for the **Update** banner, or run *Check for updates* from the command palette. You can also download `JiydaSetup-0.6.3.exe` below.
