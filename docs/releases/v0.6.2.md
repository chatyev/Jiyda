Space colors across the whole window, category filters in Orbit, and fixes for a crash and two annoying bugs.

## New

- **Your Space's color now fills the window.** The top bar is a gradient in the Space color with a slow shimmer of neighboring hues. New Page glows in the same colors, and Split View headers and the dimming behind Orbit and the command palette are tinted to match. Switching Spaces or changing a Space's color now blends smoothly instead of jumping. With reduced motion turned on in Windows or in Settings, nothing animates.
- **Filter Orbit by category.** A row of filters above your pages: *All*, plus categories such as Development, Documentation or a site you have many pages from, each with a page count. Filters work together with search and reset to *All* each time you open Orbit.

## Fixes

- **Fixed a crash when opening a page.** If a page opened at the same moment a background timer fired (for example autosave), Jiyda could quit unexpectedly.
- **You can always create a new Space.** After creating and deleting Spaces about eight times in one session, Jiyda refused to create another one ("You can't have more than 9 Spaces"), even with only one Space left.
- **Ctrl+Tab, then Ctrl+Shift+Tab returns to the page you started from,** like Alt+Tab in Windows. Before, it got stuck on the second page.

## Security

- **Updates are verified before they install.** Each release now publishes a SHA-256 checksum next to the installer. From this version on, Jiyda checks it and refuses to run an installer that is damaged or was altered on the way.
- Dependencies are checked on every build for known vulnerabilities and license issues.

## Install

Jiyda updates itself: wait for the **Update** banner, or run *Check for updates* from the command palette. You can also download `JiydaSetup-0.6.2.exe` below.
