Bookmarks you can dock to the side, a Beta channel for updates, stronger protection for Jiyda itself, and almost no CPU use while idle.

## New

- **Dock bookmarks to the side.** In the bookmarks panel, press the pin to keep it open on the right, full height. The page makes room for it instead of being covered, and other panels no longer close it. Press it again to make the panel float over the page.
- **Drag and drop bookmarks.** Drag a bookmark onto a folder to move it inside, or above or below another bookmark to reorder.
- **Bookmarks as an HTML file.** The ⋯ menu in the bookmarks panel can save all bookmarks to an HTML file in your Downloads folder, and import such a file from Chrome, Edge, Firefox or Safari. Bookmarks you already have are not duplicated.
- **Beta versions.** Settings → General → *Beta versions* gets new versions a few days before everyone else. They may have more bugs; turn it off to go back to regular releases.

## Changes

- **Almost no CPU while idle.** An animated highlight in the top bar and a hidden loading indicator kept redrawing Jiyda all the time. They no longer do: with one page open, Jiyda now uses about 0.1% of a processor core while idle, down from about 13%.
- **A bookmark edit is no longer lost** when you click outside the panel; Esc and *Cancel* still discard it.
- **The welcome tour** now opens with “Every page in its place.”

## Security

- Jiyda’s own interface now accepts commands only from itself and can only show its own pages. Links it opens become regular Jiyda pages.
- The interface can no longer load anything from the internet (a strict Content Security Policy).
- A website can no longer start *Ask Jiyda* actions over and over: at most three times a minute, since each is a paid request with your API key.

## Install

Jiyda updates itself: wait for the **Update** banner, or run *Check for updates* from the command palette. You can also download `JiydaSetup-0.6.5.exe` below.
