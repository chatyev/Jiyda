A bug-fix release.

## Fixes

- **Context menu hidden behind the page.** Right-clicking a tab near the sidebar's right edge (almost always the right half of a Split View pair) opened the menu partly behind the web page. The menu now always stays inside the sidebar.
- **Keyboard shortcuts in an empty window.** With no tabs open, Ctrl+T and other shortcuts did nothing until you clicked inside the window. Seyro now moves keyboard focus to the right place whenever its window is activated, whether you launch it, Alt+Tab to it or click it on the taskbar.
- **More reliable shortcuts.** Sidebar and palette shortcuts now also work in setups where Windows doesn't report the physical key, such as some remote desktop sessions.

## Install

Download `SeyroSetup-0.2.1.exe` below and run it. It upgrades an existing installation in place, and closes Seyro first if it's running. Your tabs, spaces and logins are kept.
