The first public release of **Seyro**, a lightweight Arc-style browser for Windows. The core is written in Rust; pages are rendered by Microsoft Edge WebView2, which is already built into Windows 10 and 11.

## Highlights

- **Vertical tabs.** Pinned tabs on top, everything else below; drag to reorder or to pin.
- **Command palette** (Ctrl+T). One box for addresses, web search, open tabs, history and browser commands.
- **Spaces with separate logins.** Each space has its own tabs, color, cookies and site data, so you can be signed in to one Google account in "Work" and another in "Personal". Switch with the icons at the bottom of the sidebar or Ctrl+Shift+1…9.
- **Split View.** Two tabs side by side with a draggable divider. Right-click a tab and choose "Open next to current", or run "Split screen" from the palette.
- **Find in page** (Ctrl+F). Highlights every match and shows "3 of 7".
- **Downloads** (Ctrl+J). Searchable list of downloaded files; pick one to show it in Explorer.
- **Frameless window.** Window controls live in the sidebar; drag the empty sidebar area to move the window. Set `"custom_titlebar": false` in `config.json` to get the standard Windows frame back.
- **Pinned tabs remember their address.** If you navigate away, a ↺ button takes you back. Ctrl+W unloads a pinned tab instead of closing it.
- **Auto-archive and tab sleep.** Unpinned tabs you haven't opened for 12 hours move to "recently closed" on startup (Ctrl+Shift+T brings them back). Background tabs you haven't opened for 60 minutes are unloaded from memory; tabs playing audio stay awake.
- **Session restore.** Tabs, spaces and split pairs come back after a restart.
- **Extensions.** Unpacked extensions from the `extensions` folder load in every space. uBlock Origin Lite works well.

## Privacy and security

- Pages can't trigger browser commands. Keyboard shortcuts are captured by WebView2 before the page sees them, so a site can't fake or block them.
- A page can open at most 10 tabs in 5 seconds.
- A pop-up from a tab in a background space opens in that space, never in the space you're currently in.
- "Clear history" and "Clear site data" (for the current space) ask for confirmation.

## Install

Download `SeyroSetup-0.2.0.exe` below and run it. It installs for the current user only, with no administrator rights needed, into `%LOCALAPPDATA%\Programs\Seyro`, and adds Start menu and (optional) desktop shortcuts. Uninstall it from Settings → Apps; your tabs, spaces and logins stay in `%LOCALAPPDATA%\Seyro`.

The installer isn't code-signed yet, so Windows SmartScreen may warn about an unknown publisher: choose **More info → Run anyway**.

**Upgrading from Drift** (the project's earlier name): on first launch Seyro moves your data from `%LOCALAPPDATA%\Drift` to `%LOCALAPPDATA%\Seyro`. Tabs, spaces and site logins are kept.

## Known limitations

- Find in page doesn't search inside text fields or frames, and misses words split across formatting (for example, partly bold).
- Only one split pair is on screen at a time.
- With `"frame_padding": 0` the window can't be resized from its right and bottom edges.
- Seyro can't be set as the default browser yet. That's coming next.
