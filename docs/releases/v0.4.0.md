Seyro now updates itself.

## New

- **Automatic updates.** Shortly after launch, and then every 12 hours, Seyro checks GitHub for a newer release. When one is available, a **"Seyro X.Y.Z — Update"** banner appears at the bottom of the sidebar. Click **Update** and Seyro downloads the installer, saves your tabs, closes, installs the new version and opens again. Click × to hide the banner until the next launch.
- **"Check for updates"** command in the palette (Ctrl+T), if you don't want to wait for the next automatic check.

## Privacy and security

- The update check is a plain request to GitHub's public API. It sends nothing about you or your browsing.
- Installers are downloaded only from this repository's release pages, over HTTPS, and are checked before they run.
- Drafts and pre-releases are never offered.
- To turn update checks off, set `"check_updates": false` in `%LOCALAPPDATA%\Seyro\config.json`.

## Install

**Coming from 0.3.0 or earlier:** these versions can't update themselves. Download `SeyroSetup-0.4.0.exe` below and run it once. Your tabs, spaces and logins are kept. From 0.4.0 onwards, updates arrive automatically.
