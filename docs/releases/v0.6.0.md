Seyro is now **Jiyda**. Same browser, new name and a new icon.

## What changes for you

- **New name and icon** everywhere: the window, the taskbar, the Start menu and the installer.
- **Your data moves over by itself.** On first launch Jiyda moves `%LOCALAPPDATA%\Seyro` to `%LOCALAPPDATA%\Jiyda`. Your pages, Spaces, logins, settings and your Ask Jiyda API key are kept.
- **Default browser stays.** If Seyro was your default browser, Jiyda takes its place and you don't have to choose again.
- The Seyro program and its shortcuts are removed. If you had Seyro **pinned to the taskbar**, pin Jiyda again.
- Ask Seyro is now called **Ask Jiyda**.

## Fixes

- **Rare freezes are fixed.** In some setups the whole browser could stop responding shortly after start. The cause was how the window handled dragging by the top bar. Dragging, snapping to screen edges, double-click to maximize and the right-click window menu still work as before.
- **Site icons are visible in both themes.** Some sites provide a white icon for dark mode, and it disappeared on the light theme. Such icons now get a contrasting backdrop.

## Install

**From Seyro 0.5.0:** wait for the **Update** banner, or run *Check for updates* from the command palette. Seyro updates to Jiyda by itself.

**Fresh install or older versions:** download `JiydaSetup-0.6.0.exe` below and run it.
