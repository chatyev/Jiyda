Seyro can now be your default browser.

## New

- **Default browser.** The installer adds Seyro to Windows' list of browsers. To make it the default, tick **"Make Seyro the default browser"** at the end of setup, or run the same command from the palette (Ctrl+T). Settings opens on Seyro's page; click **Set default**. Windows doesn't let apps set themselves as default without asking, so the final click is yours.
- **Links from other apps** (Telegram, email, documents) open as new tabs in your existing Seyro window, and the window comes to the front.
- **Open files and links from the command line.** `seyro.exe https://example.com` or `seyro.exe page.html` opens them in a tab. Double-clicking an `.html` file works too once Seyro handles that file type.

## Fixes

- **Only one Seyro window.** Launching Seyro while it's already running now brings the existing window to the front instead of starting a second copy on the same profile data, which could corrupt it.

## Security

Links passed from other programs are accepted only from your own Windows account, and only as `http`, `https`, `file` or `about` addresses.

## Install

Download `SeyroSetup-0.3.0.exe` below and run it. It upgrades an existing installation in place and keeps your tabs, spaces and logins. The browser registration is removed again if you uninstall Seyro.
