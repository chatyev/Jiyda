A small fix for update checks.

## Fixes

- **"Check for updates" no longer fails with "Is GitHub reachable?"** Jiyda asked GitHub's API for the latest version, and the API only allows 60 requests per hour per network address without signing in. Behind a shared office or home router that limit runs out quickly. Jiyda now reads the latest version from the public releases page, which has no such limit.
- If GitHub does limit requests, the message now says so: "GitHub is limiting update checks right now. Try again later."
- Update checks no longer depend on the letter case of the repository name.

## Install

Jiyda 0.6.0 updates itself: wait for the **Update** banner, or run *Check for updates* from the command palette. If that check fails, wait an hour and try again. You can also download `JiydaSetup-0.6.1.exe` below.
