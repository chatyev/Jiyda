# Бенчмарки Jiyda (план, раздел 32)

Воспроизводимые замеры Jiyda против Microsoft Edge и Google Chrome на одной машине.
Результаты — в `results/<дата>.md` и `.json` (все прогоны, не только медианы).

## Запуск

```powershell
cargo build --release
./bench/run.ps1                                   # Jiyda, Edge, Chrome; 1, 10, 50 страниц; 3 прогона
./bench/run.ps1 -Browsers jiyda,chrome -Runs 5    # из PowerShell: список через запятую
```

Во время прогона на экране открываются окна браузеров (с отдельными пустыми профилями —
ваши профили не трогаются). Не работайте за машиной: фоновая нагрузка искажает процессор.

## Что меряется

| Метрика | Как |
|---|---|
| Запуск до первой страницы | от старта процесса до события `load` первой страницы |
| Все страницы загружены | до `load` последней из N страниц, открытых из командной строки |
| Память | сумма Working Set и Private Bytes всех процессов браузера (главный, страницы, GPU…) через 10 с после загрузки |
| Процессор в простое | процессорное время всех этих процессов за 20 с без действий, % одного ядра |

- Страница — `page.html`: статья с текстом, таблицами и картинками SVG, без анимаций и сети.
- Каждая страница — со своего адреса `127.0.0.<k>` (`server.ps1`): N страниц — N разных
  сайтов, как обычные вкладки. Браузеры делят процессы по сайтам, и одинаковый адрес у
  всех страниц исказил бы память в пользу Chrome и Edge.
- Каждый прогон — новый пустой профиль; перед замерами один прогрев не считается.
- Итог — медиана прогонов.

## Чего эти цифры не говорят

- **Батарея** и **доля сессий без сбоев** не меряются: нужны долгие наблюдения на ноутбуках
  (сбои — из статистики «Помочь улучшить Jiyda», telemetry/metrics.sql).
- Открыть 50 страниц разом из командной строки — нечастый сценарий; при восстановлении
  сессии Jiyda не загружает страницы сразу (они «спят», пока их не откроют).
- Одна машина и одна версия каждого браузера — смотрите строку окружения в результатах.
- Никаких «в N раз быстрее Chrome» без ссылки на конкретный файл результатов.

## Найдено бенчмарками

- 19.10.2026 (results/2026-10-19.md): с 10 и 50 страницами Jiyda нужно в 1,7–2 раза больше
  частной памяти, чем Edge и Chrome, а 50 страниц разом она открывает в 7–10 раз дольше
  (каждая страница — свой WebView2, создаются по очереди). С одной страницей памяти меньше,
  чем у обоих. Задача на улучшение.
- 19.10.2026: бесконечный перелив верхней панели и невидимый бегунок загрузки
  перерисовывали интерфейс каждый кадр — ~13% ядра в простое с одной страницей. Убраны:
  теперь ~0,1%.
